firstmate_status :: What is happening now: notes waiting, in-flight backlog items, each crew's last event (fm-inbox.sh status), and whether firstmate itself is live to receive notes (fm-inbox.sh ready). When the session lock is stale, it says: firstmate liveness cannot be proven right now; notes are still saved and queued, and firstmate picks them up the next time its session runs. Sends no wake and never interrupts firstmate.

Read-only: this tool never spawns, steers, merges, tears down, or edits backlog or state; to ask for any of that, send firstmate a note with firstmate_send_note.
